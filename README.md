# Student Score Analyzer

An interactive Streamlit application for analyzing student academic performance across multiple subjects.

## Project Overview

Teachers often need to quickly understand how students are performing across different subjects. Manually calculating averages, grades, pass/fail status, and class performance can be time-consuming.

I built this application to automate these basic calculations and present the results in a simple, interactive dashboard.

## Project Objectives

The application was designed to:

* Record students' scores across multiple subjects
* Automatically calculate students' average scores
* Assign grades based on average performance
* Determine pass/fail status
* Identify the highest-performing students
* Analyze average performance across subjects
* Visualize student and class performance

## Features

### Student Performance

* Add student names and scores
* Calculate individual average scores
* Automatically assign grades
* Determine pass/fail status

### Class Analysis

* Calculate class average
* Identify highest-performing students
* Count students who passed and failed
* Compare performance across subjects

### Data Visualization

* Subject performance chart
* Student average score chart
* Grade distribution chart

### Performance Insights

The application identifies the strongest and weakest-performing subjects based on class averages.

## How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/olanrewajuesther3319/Student_Score_Analyzer.git
```

### 2. Navigate into the project

```bash
cd Student_Score_Analyzer
```

### 3. Install the dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```

The application will open in your browser.
